# Frontend Instructions

This folder contains the vanilla HTML, CSS, and JS files for the Goa Tour Travel project.

No build tools (like Webpack or Vite) are required. 
Simply open the HTML files in a browser or use a local development server (like VSCode Live Server).

Ensure the backend server is running and the API base URL in `js/main.js` points to the correct backend address (default: `http://localhost:5000`).
